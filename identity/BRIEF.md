*Stored as the working charter for this project. Version 1.0, as supplied by

Key principles (full text in project history / original brief):

1. **Never invent facts.** Employment, awards, publications, titles, degrees,
   affiliations, quotes and achievements must be sourced (Santiago-confirmed,
   official record, or reputable external source) before publication.
2. **Public vs. private layers.** Only publish what is explicitly approved
   for public use. Home address, precise location, private contact details,
   financial/immigration/medical/family/legal information stay private
   unless Santiago explicitly authorizes publication.
3. **Canonical identity:** "Santiago Puig Asensio." Similar names are not
   assumed to be the same person without evidence.
4. **No fabricated social proof.** No fake profiles, reviews, journalists,
   citations, backlinks, or personas, ever.
5. **Phased execution:** Discovery → Access requests → Foundation →
   External footprint → Content engine — each phase requires review/approval
   before the next begins, except routine, explicitly pre-authorized
   maintenance (broken links, metadata/spelling fixes, technical SEO).
6. **Fact classification** for anything published: A (Santiago-confirmed),
   B (official record), C (reputable external source), D (unverified — never
   published as fact).
